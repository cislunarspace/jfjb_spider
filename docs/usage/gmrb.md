# 光明日报爬虫

通过 HTML 页面解析抓取光明日报各版面文章。

## 基本用法

```bash
# 抓取今天的报纸
uv run python -m newspaper_pdf.gmrb_spider

# 抓取指定日期
uv run python -m newspaper_pdf.gmrb_spider --date 2026-03-10
```

## 工作流程

光明日报使用 HTML 页面（而非 JSON API），爬虫分三步抓取：

1. **发现版面** — 访问第一个版面页，从版面目录获取所有版面链接
2. **提取文章** — 从每个版面页的标题目录（`.m-title-list`）提取文章链接和版面名称
3. **解析内容** — 逐个访问文章页，提取标题、引题/副题、作者和正文

## 编码处理

光明日报网站使用 UTF-8 编码。爬虫沿用统一的响应解码逻辑：优先遵循 HTML `<meta charset>` 声明，回退到自动检测。

## 专用参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--base-url` | 站点根地址 | `https://epaper.gmw.cn` |

## 与其他爬虫的区别

| 特性 | 解放军报 | 人民日报 | 光明日报 |
|------|----------|----------|----------|
| 数据格式 | JSON API | HTML 页面 | HTML 页面 |
| 批量抓取 | 支持 | 不支持 | 不支持 |
| 默认输出目录 | `output/` | `output/rmrb/` | `output/gmrb/` |
| 编码 | UTF-8 | GB2312/GBK（自动检测） | UTF-8 |
