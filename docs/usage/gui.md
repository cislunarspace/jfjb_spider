# GUI 界面

图形界面提供直观的方式来配置抓取任务和浏览结果。

## 启动方式

```bash
uv run newspaper-pdf-ui
```

## 界面布局

主窗口分为两个 Tab：

### 抓取面板

- **报纸类型**：选择解放军报或人民日报
- **模式**：单日抓取或批量抓取
- **日期选择**：选择目标日期（单日模式）或起止日期（批量模式）
- **输出目录**：指定 PDF 文件的输出位置
- **开始抓取**：启动后台抓取任务
- **进度显示**：实时显示抓取进度和日志

### 结果浏览面板

- **目录树**：以树形结构浏览输出目录
- **PDF 预览**：选中 PDF 文件后，在嵌入式浏览器中预览
- **自动定位**：抓取完成后自动切换到最新输出目录

## 工作原理

GUI 在后台运行抓取任务，不会阻塞界面响应。抓取完成后会自动提示切换到结果浏览面板查看输出文件。
